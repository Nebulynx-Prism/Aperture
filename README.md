## System Requirements

### Streamer

|  | Minimum | Recommended |
| --- | --- | --- |
| **OS** | Windows 11 24H2, Linux Mint 22, or newer. | Windows 11 (latest release), CachyOS, or other distros. |
| **CPU** | Intel Core i5-4590 / AMD FX 8350 / ARM Cortex-A76 | Intel Core i5 (10th gen or newer) / AMD Ryzen 3 (3000-series or newer) / Qualcomm Snapdragon 8 Gen 3 |
| **GPU** | Arc 140V, Radeon R9 290, GTX 970, or Mali-G76 | Arc A580, Radeon RX 480, GTX 1060, or Adreno 750 |
| **RAM** | 8GB or more | 16GB or more |

> [!NOTE]
> Most system requirements are copied from SteamVR's requirements page.

> [!IMPORTANT]
> SteamVR needs to be installed for PCVR functionality to work.

---
### Client

|  | Minimum | Recommended |
| --- | --- | --- |
| **Quest Headsets** | Quest 2* and Quest 3/3S | Meta VR Glasses and Quest Pro* |
| **Pico Headsets** | Pico 4 | Pico 4 Ultra |
| **Steam Headsets** | - | Steam Frame |

> [!IMPORTANT]
> Quest 2 & Quest Pro will not support installation through the Horizon Store. Installing through Sidequest, GitHub, or Obtainium is recommended.

## Installation

1. Download the [server](https://github.com/Nebulynx-Prism/Aperture/releases/download/v0.1.0/Aperture-Setup.exe) & the [client](https://github.com/Nebulynx-Prism/Aperture/releases/download/v0.1.0/Aperture-Quest.apk)
2. Install the server and the client
3. Load up and enjoy!

> [!NOTE]
> You can use Obtainium for the client on supported devices.

> [!IMPORTANT]
> To install the client, please view this [article](https://www.uploadvr.com/sideloading-quest-how-to/) on how to install 3rd party apps on Quest headsets.

> [!IMPORTANT]
> To use Aperture on Windows, MSVC++ needs to be installed. This requirement will be removed in the future when a Linux version comes out. 

## AI Notice

Aperture is built using Claude 4.6 Opus, GPT-6 Astra, and Gemini 3.8 Flash in Rust, thanks to the use of Google Antigravity & OpenAI Codex.

All code must be written by a human in pull requests as all AI code is a temporary thing due to reverse engineering Virtual Desktop Software. We want to get rid of most vibecoded parts of the software following this.
